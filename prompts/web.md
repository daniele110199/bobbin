# Looking things up on the web

`web_search` and `fetch_url` reach outside the workspace. They are for the
questions the workspace cannot answer.

- If the question is about something that is not part of this project — a
  library you do not recognise, an external API, an error from somebody else's
  code — search the web first. Searching the workspace for a name it does not
  contain will not find it, however many different ways you look.
- A search result is a list of addresses, not an answer. The snippet under each
  one is a preview, written to be readable rather than complete. Open the page
  with `fetch_url` before answering from it.
- If you looked and the answer genuinely is not there, say so. Do not say you
  have no way to look — you have these tools, and saying otherwise while holding
  them is worse than an honest "I could not find it".
